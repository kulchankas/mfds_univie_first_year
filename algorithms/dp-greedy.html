Dynamic programming & greedy

Nineteen problems across two sheets — the largest single block on the course, and entirely absent from the first-date paper. Almost all of them are one of four DP shapes or one exchange argument in disguise. Learn the shapes and the problems collapse.

The two hallmarks

Dynamic programming applies when 1 · Optimal substructure — an optimal solution is built from optimal solutions to subproblems.
2 · Overlapping subproblems — the naive recursion solves the same subproblem many times, so caching pays.

Miss the first and DP is wrong; miss the second and DP is merely pointless (plain divide-and-conquer already suffices — merge sort has optimal substructure but no overlap).

Two implementations, same table: top-down with memoisation (write the recursion, cache on first computation) and bottom-up (order subproblems by size, fill iteratively). Bottom-up is usually faster by a constant; top-down only touches the subproblems it actually needs.

Runtime, at a glance $\text{time} = (\text{number of subproblems})\times(\text{choices per subproblem})$. A 1-D table with $O(n)$ choices is $O(n^2)$; a 2-D interval table with $O(n)$ split points is $O(n^3)$. You can read the exponent off the shape before writing a line of code.

Shape 1 — linear DP PROB 81, 82, 85, 88

Rod cutting, the base case

A rod of length $n$, prices $p_1..p_n$; maximise revenue. The last decision is "how long is the first piece?": $$r_0=0,\qquad r_n=\max_{1\le i\le n}\big(p_i+r_{n-i}\big).$$ $n$ subproblems, $O(n)$ choices each: $O(n^2)$. Record the argmax in a second array s[n] to reconstruct the cuts.

BOTTOM-UP-CUT-ROD(p, n)
  r[0] = 0
  for j = 1 to n:
    q = −∞
    for i = 1 to j:
      if q < p[i] + r[j−i]:
        q = p[i] + r[j−i];  s[j] = i        // first piece length
    r[j] = q
  return r, s

Variant — a fixed cost per cut PROB 82

Each cut costs $c$. Selling the rod whole involves no cut, so that case must be separated out: $$r_n=\max\Big(p_n,\ \max_{1\le i<n}\big(p_i+r_{n-i}-c\big)\Big).$$ Getting the $p_n$ term right is the whole problem — folding it into the general max would charge you for a cut you never made.

Variant — production planning PROB 88

The Rinky Dink problem is linear DP with a second dimension for carried stock: let $C[i,j]$ be the cheapest way to finish month $i$ holding $j$ machines. From $C[i-1,\cdot]$ you choose this month's production, paying overtime above $m$ units and holding cost $h(j)$. Subproblems $n\times D$, choices $O(D)$ ⇒ polynomial in $n$ and $D$, as required.

Shape 2 — interval DP PROB 83, 84, 87, 89, 90–92

One pattern, five problems Subproblem = a contiguous range $[i,j]$; the last decision is where to split it. Every one of matrix-chain, optimal BST, longest palindromic subsequence, string breaking and bitonic TSP is this. Fill the table by increasing interval length, so both halves are ready.

Matrix-chain multiplication — the archetype

$$m[i,i]=0,\qquad m[i,j]=\min_{i\le k<j}\big(m[i,k]+m[k+1,j]+p_{i-1}p_kp_j\big).$$

$\Theta(n^2)$ subproblems × $O(n)$ split points $=\Theta(n^3)$. Problem 83 asks for the total number of table references, which telescopes to $\sum_{i}\sum_{j}R(i,j)=\frac{n^3-n}{3}$ — a useful sanity check that the work really is cubic.

Optimal binary search tree PROB 90, 91

Same skeleton, but the "split point" is the root of the subtree, and every key in the range sinks one level deeper when you attach it: $$e[i,j]=\min_{i\le r\le j}\Big(e[i,r-1]+e[r+1,j]+w(i,j)\Big),\qquad w(i,j)=\sum_{l=i}^{j}p_l+\sum_{l=i-1}^{j}q_l.$$ The $+w(i,j)$ term is the whole idea: it charges every key in the interval for the extra level. Problem 90 wants CONSTRUCT-OPTIMAL-BST, which just reads the root table recursively:

CONSTRUCT-OPTIMAL-BST(root, n)
  r = root[1, n]
  print "k" r "is the root"
  CONSTRUCT-SUBTREE(root, 1, r−1, r, "left")
  CONSTRUCT-SUBTREE(root, r+1, n, r, "right")

CONSTRUCT-SUBTREE(root, i, j, parent, side)
  if i > j:
    print "d" j "is the" side "child of k" parent      // dummy leaf
  else:
    r = root[i, j]
    print "k" r "is the" side "child of k" parent
    CONSTRUCT-SUBTREE(root, i, r−1, r, "left")
    CONSTRUCT-SUBTREE(root, r+1, j, r, "right")

Longest palindromic subsequence PROB 87

$$L[i,i]=1,\qquad L[i,j]=\begin{cases}L[i+1,j-1]+2 & s_i=s_j\\[2pt] \max\big(L[i+1,j],\,L[i,j-1]\big)&\text{otherwise.}\end{cases}$$

$\Theta(n^2)$ subproblems, $O(1)$ choices ⇒ $\Theta(n^2)$. Shortcut worth knowing: the answer equals $\mathrm{LCS}(s,\operatorname{reverse}(s))$ — same complexity, and a one-line reduction if you have LCS to hand.

String breaking PROB 89

Breaking a string of $n$ characters at given points, each break costing the current substring's length. With sentinels $L_0=0$ and $L_{m+1}=n$: $$C[i,j]=\big(L_j-L_i\big)+\min_{i<k<j}\big(C[i,k]+C[k,j]\big),\qquad C[i,i+1]=0.$$ This is matrix-chain with different labels. Recognising that is the entire exercise.

Shape 3 — tree DP PROB 93

The company party: maximise total conviviality with the rule that no employee attends alongside their immediate supervisor — i.e. a maximum-weight independent set on a tree. Keep two values per node:

$$\mathrm{in}(v)=c_v+\sum_{u\in\text{children}(v)}\mathrm{out}(u),\qquad \mathrm{out}(v)=\sum_{u\in\text{children}(v)}\max\big(\mathrm{in}(u),\mathrm{out}(u)\big).$$

Answer: $\max(\mathrm{in}(root),\mathrm{out}(root))$. One post-order pass, $O(1)$ work per child, so $O(n)$ overall — with the left-child/right-sibling representation you simply walk the sibling list. Reconstruct the guest list by re-descending and taking whichever branch achieved the max.

The general tree-DP move When a node's choice constrains its children, carry one value per state of the node (here: in the set / out of it) and combine children independently. The same shape solves tree vertex cover, tree colouring, and tree matching.

0–1 knapsack PROB 99: with $K[i,w]$ the best value from the first $i$ items under capacity $w$, $$K[i,w]=\begin{cases}K[i-1,w] & w_i>w\\[2pt]\max\big(K[i-1,w],\ v_i+K[i-1,\,w-w_i]\big)&\text{otherwise,}\end{cases}$$ with $K[0,w]=0$. Table $n\times W$, $O(1)$ per cell ⇒ $O(nW)$.

Why $O(nW)$ is not polynomial The input encodes $W$ in $\Theta(\lg W)$ bits, so $O(nW)$ is exponential in the input length — this is pseudo-polynomial. It is why 0–1 knapsack is NP-hard while the fractional version is linear-time. Say this if asked to compare them; it is the point of setting the two problems together.

When optimal substructure fails PROB 85

Add a limit $l_i$ on how many pieces of length $i$ may be produced. Now optimal substructure breaks: an optimal solution to the length-$n$ problem no longer decomposes into an optimal solution to the length-$(n-i)$ problem, because the sub-solution's choices consume quota that the outer problem also needs. The subproblem is no longer "a rod of length $n-i$" — it is "a rod of length $n-i$ with these remaining quotas", a different and much larger state space.

The general diagnosis Optimal substructure fails whenever subproblems compete for a shared resource. The repair is always the same: enlarge the state to include the resource (here, the remaining quota vector) — at the cost of an exponentially bigger table. Problem 85 wants you to notice the failure, not repair it.

Greedy algorithms PROB 94–98

The two ingredients 1 · Greedy-choice property — some optimal solution is consistent with the locally best choice. Proved by an exchange argument.
2 · Optimal substructure — after the greedy choice, what remains is the same problem on a smaller instance.

Greedy is DP where one choice is provably safe, so you never have to compare alternatives.

The exchange-argument template

Every greedy proof on this course — activity selection, Huffman, fractional knapsack — is this skeleton. Memorise it and fill in the middle:

  1. Let $A$ be any optimal solution, and $g$ the greedy first choice.
  2. If $g\in A$, done. Otherwise let $a\in A$ be the element the greedy rule would have beaten.
  3. Form $A'=(A\setminus\{a\})\cup\{g\}$. Show (i) $A'$ is still feasible, and (ii) $A'$ is no worse than $A$.
  4. Then $A'$ is also optimal and contains $g$ — so some optimal solution makes the greedy choice.
  5. Induct on the residual problem.

Compare the three instances: activity selection (Thm 15.1) exchanges the earliest finisher; Huffman (Lemma 15.2) exchanges the two rarest symbols to the deepest level; fractional knapsack exchanges weight into the densest item. Same five steps every time.

Activity selection, and its mirror PROB 94

The standard rule takes the earliest-finishing compatible activity. Problem 94 asks about taking the last-to-start instead — and it is also optimal, because it is literally the same algorithm on time reversed: reverse the axis ($t\mapsto-t$), and "last to start" becomes "first to finish". The exchange argument transfers verbatim.

The moral: a plausible-sounding local rule is worth nothing without an exchange argument. Only earliest-finish leaves the most room for what follows — which is exactly what step 3(i) of the template verifies.

Fractional knapsack has the greedy-choice property PROB 98

Claim. Some optimal solution takes as much as possible of the item with maximum density $v_1/w_1$.

Proof. Let $A$ be optimal and suppose it takes $x<\min(w_1,W)$ of item 1. Then $A$ must carry weight elsewhere, in items of density $\le v_1/w_1$. Remove $\delta>0$ weight of some such item $j$ and add $\delta$ of item 1 (possible since $x<w_1$). The value changes by $$\delta\Big(\frac{v_1}{w_1}-\frac{v_j}{w_j}\Big)\ \ge\ 0,$$ and the total weight is unchanged, so the result is still feasible and no worse. Repeating drives item 1 to its maximum. $\blacksquare$

Linear time without sorting: you need the weighted median by density, which median-of-medians selection finds in $O(n)$; recurse on the half that the capacity does not resolve — $T(n)=T(n/2)+O(n)=O(n)$.

Two more from sheet 10

  • Fewest lecture halls PROB 96 — interval-graph colouring. Sweep activities by start time, keeping a min-heap of rooms keyed by their current end time: reuse the earliest-freeing room if it is free, else open a new one. $O(n\lg n)$, and the number of rooms equals the maximum number of simultaneously active intervals.
  • Weighted activity selection PROB 97 — greedy fails once activities carry values (a single high-value long activity can beat many cheap ones). Sort by finish time and do DP: $\mathrm{OPT}(j)=\max\big(v_j+\mathrm{OPT}(\mathrm{prev}(j)),\ \mathrm{OPT}(j-1)\big)$, where $\mathrm{prev}(j)$ is the last activity finishing before $j$ starts, found by binary search. $O(n\lg n)$.
The exam-shaped summary Sheet 10 is built to teach one lesson: unweighted activity selection is greedy; add weights and it becomes DP; make the knapsack fractional and it is greedy again; make it 0–1 and it is DP. If asked "greedy or DP?", the answer is decided by whether an exchange argument survives — and problems 95 and 97 are the two places it does not.
